# ILP – Erste Schritte mit CSS

Gestalte drei kleine Webseiten: mit Farben und Klassen, unterschiedlichen Schriftgrößen und Textformatierungen sowie verschieden breiten Textabsätzen. Bearbeite die Übungen der Reihe nach.

1. [Farben und Selektoren](01-farben-selektoren/task-de.md)
2. [Schriftgrößen ausprobieren](02-schriftgroessen/task-de.md)
3. [Textbreiten entdecken](03-textbreiten/task-de.md)

## So arbeitest du

- Erstelle in jedem Aufgabenordner selbst eine `index.html` und eine `style.css`. Das HTML-Grundgerüst kannst du in VS Code mit `!` und Enter erzeugen.
- Kopiere die Seitentexte aus der jeweiligen `texte.txt`. Die Beschriftungen in dieser Datei dienen nur zur Orientierung und gehören nicht auf die Webseite.
- Verbinde dein HTML im `<head>` mit der CSS-Datei: `<link rel="stylesheet" href="style.css">`.
- Öffne deine `index.html` im Browser und lade sie nach Änderungen neu. Vergleiche dein Ergebnis mit dem Bild und den Fertigkriterien der Aufgabe.

Nutze externe Stylesheets, Element- und Klassenselektoren. Neue Inhalte werden direkt in den Aufgaben eingeführt, darunter die Liste in Aufgabe 1. ID-Selektoren werden nicht gebraucht. Dein Ergebnis sind die selbst erstellten HTML- und CSS-Dateien.

Die Referenzbilder zeigen jeweils einen Seitenbereich von **1100 × 800 Pixeln** bei **100 % Browserzoom**. Andere Fenstergrößen und verfügbare Schriftarten können Zeilenumbrüche leicht verändern. Zusätzliche Abstände oder ein aufwendiges Layout sind nicht nötig.

Die englische Übersicht steht in [README_en.md](README_en.md).
