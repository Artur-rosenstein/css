# ILP – First steps with CSS

Style three small webpages: with colours and classes, different font sizes and text formatting, and text paragraphs of different widths. Complete the exercises in order.

1. [Colours and selectors](01-farben-selektoren/task-en.md)
2. [Experiment with font sizes](02-schriftgroessen/task-en.md)
3. [Discover text widths](03-textbreiten/task-en.md)

## How to work

- Create your own `index.html` and `style.css` in each exercise folder. In VS Code, type `!` and press Enter to generate the HTML boilerplate.
- Copy the page texts from each `texte.txt`. The labels in that file are for orientation only and do not belong on the webpage. Both language versions use the same German page texts and reference images.
- Connect your HTML to the CSS file inside `<head>`: `<link rel="stylesheet" href="style.css">`.
- Open your `index.html` in a browser and reload after changes. Compare your result with the image and completion criteria in the exercise.

Use external stylesheets, type selectors, and class selectors. New topics are introduced directly in the exercises, including the list in exercise 1. ID selectors are not needed. Your result consists of the HTML and CSS files you create yourself.

Each reference image shows a **1100 × 800 pixel** page area at **100% browser zoom**. Different window sizes and available fonts may slightly change line breaks. Additional spacing or a complex layout is not necessary.

The German overview is in [README.md](README.md).
